# Image prompts (Gemini app)

Paste each prompt into Gemini (image generation) and set the **aspect ratio** shown.
Make 2–3 attempts per shot and keep your favourite. Save it as **`assets-src/images/<id>.png`**
(exact filename, PNG or JPG, the highest resolution Gemini offers). I handle cropping, compression and responsive sizes.

**Reject any image with** warped hands or faces, readable text or logos, people staring into the camera, or a plastic "stock photo" look.
These images are illustrative only. We never attach real names or testimonials to them.

Imigongo textures are drawn in code, so they don't need prompts.
